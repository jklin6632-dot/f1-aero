# F1 2024 · 空气动力学展示（单页 Three.js）

法拉利 SF-25 的浏览器内 3D 展示 + 空气动力学交互演示。全部计算在页内完成，不依赖任何后端或物理引擎。

**版本 v1.0**（定型版，见页脚 build 标记）

> **在线演示**：https://phenomenal-cannoli-230ed4.netlify.app 　（首次加载约 22 MB，之后走浏览器缓存）
> **一句话**：涡格法（VLM）在浏览器里算 8 条翼面 / 396 个涡环，再把结果画成粒子和压力色——不是 CFD。
>

## 运行

三种打开方式，任选：

1. **双击桌面「F1 AERO」图标**（项目文件夹里也有一份）—— 启动器 `_launch.vbs` 在后台起服务器（已在跑就跳过，不会起第二份），端口就绪后自动打开页面；全程不闪黑窗。
2. **双击 `index.html`** —— 页面会先探一下 `http://127.0.0.1:8141`，服务器在就自动跳过去；不在就显示提示并每 2 秒重试，服务器一起来自动跳转。
3. 手动：`node serve.mjs`（默认 `http://127.0.0.1:8141`）或双击 `start.cmd`。

> 为什么不能真的用 `file://` 跑：41 MB 的 `sf25.glb` 用 `fetch` 加载，`file://` 会被 CORS 拦，只能看到兜底几何车。所以 `index.html` 里带了一小段 file:// 引导脚本做自动跳转。

**没有开机自启**：服务器只在你点启动器（或 `start.cmd`）时才起；关掉浏览器窗口不会停服务器，重启或注销后自然就没了。

需要 Node ≥ 18（只用标准库，无 npm 依赖）与支持 WebGL2 的浏览器（本机 Edge / Chrome 均可）。

## 气动模型（结论与边界）

涡格法（VLM）解 8 条翼面 **396 个涡环** + 地板一维通道，一次求解约 150 ms，然后按 `CL_raw` 单系数标定到目标值。

- 整车：`CL 3.500 / CD 1.000 / L÷D 3.50`，250 km/h 下压力 **1581 kg**
- DRS 开：`ΔCL −8.9% / ΔCD −23.4%` → `1440 kg / CD 0.766 / L÷D 4.16`
- 前后配比 41% : 59%（前翼 1.447 / 尾翼+梁翼 0.405 / 地板 1.525）
- 边界层：Thwaites + Michel + Ludwieg–Tillmann，`CD_f = 0.0034`（250 km/h 全附着）
- 粒子场：8000 条流线，域 `z ∈ [−3.2, 12.0] m`，逐网格 AABB 遮挡，`insidePct = 0`

**明确未做的**：非定常 / 粘性 / LES / DNS；尾流卷起、湍流强度、尾翼动量亏损都是**半经验模型**，代码注释与图例里都标了「VLM 近似场，非 CFD」。`SDS.md` 附录 F 有完整的数据自洽审计与已知偏差（含模型总高 1.191 m 与规则 0.950 m 的口径差异）。

## 本地跑起来

```bash
node serve.mjs          # 默认 http://127.0.0.1:8141
```

Windows 上双击 `start.cmd` 或「F1 AERO」快捷方式即可（已在跑就不会起第二份）。

> 不能直接双击 `index.html`：模型用 `fetch` 加载，`file://` 会被 CORS 拦。
> 页面里带了一小段引导脚本，检测到 `file://` 会提示并从 8141 重试。

1. 仓库 Settings → Pages → **Source: Deploy from a branch**
2. Branch 选 `main`，目录选 **`/docs`**，Save
3. 等 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

`docs/` 里的相对路径已经处理好，跟仓库名无关，改仓库名也不用改代码。

## 已知限制

- 气动结果是 **VLM 涡格法 + 半经验修正**，不是 CFD，不能当工程依据；
- 手机端未做适配（左栏占 184 px、字号 9–11 px、快捷键依赖键盘），建议桌面浏览器；
- 微信内置浏览器 X5 老内核不支持 WebGL2，会白屏；需要 Chrome/Edge 88+、Safari 14+、iOS 14+；
- 首次加载 22 MB 模型（源码版 40 MB），慢；之后走浏览器缓存。
